# XXSE

Monster Hunter XX (3DS / Switch) のセーブエディタです。

**Alpha v0.3.1**

## 動作環境

| 版 | 動くところ |
|---|---|
| XXSE.nro | Nintendo Switch（Atmosphere 1.12 以降 / ファーム 23.0.1 で確認） |
| XXSE.exe | Windows 10 / 11 |

## できること

### セーブ編集

- ハンター（名前・所持金・HR・各種ポイント・声・髪型・顔・9色のカラー）
- アイテム BOX（個数・一括 99・重複整理・空き詰め・上限丸め）
- お守り（11 種類・スキル・ポイント・スロット）
- 装備（作成・差し替え・削除・レベル・装飾品・着せ替え）
- マイセット（装備 / アイテム、ポーチ連携）
- オトモ（名前・レベル・なつき・経験値・スキル・サポート行動・装備）
- 狩猟記録（討伐・捕獲・サイズ、未狩猟のモンスターも表示可）
- ギルドカード（武器使用数・称号・履歴・クエスト回数・闘技大会・カード名）
- 進行状況（勲章・依頼・クエストのクリア / 既読 / 失敗）
- DLC クエスト・配信オトモ
- 3DS ↔ Switch の形式変換
- 名前に改行を入れられます（ハンター名・オトモ名・マイセット名・ギルドカード名・コメント）

### お守り

11 種類（兵士 / 闘士 / 騎士 / 城塞 / 女王 / 王 / 龍 / 英雄 / 伝説 / 天）を選べます。
上限は `romfs` の護石テーブル（`amuletSkillData00..07`）から読んだ**実データ**で、種類とスキルごとに違います。

- スロット上限 … 1 / 2 / 3 / 3
- スキルごとのポイント上限 … 表のとおり（例: 攻撃 +10、聴覚保護 +7）
- 兵士・闘士は第 2 スキルを持てません
- スキルは種類と枠で選べるものだけが出ます

### クエスト

- 条件 (.mib): 報酬・時間・マップ・初期位置・大型モンスター 5 枠
- 初期配置 (.sem): エリア番号・座標・向き・出現ウェーブ
- 文章 (.gmd): クエスト名・依頼主・依頼内容・成功 / 失敗条件
- 報酬 / 支給品 (.rem / .sup)、小型配置 (.esl)、整合性検査
  - 報酬の**確率 %** を編集できます（グループの合計が 100% でない場合は警告）
- セーブへの導入・セーブ内クエストの削除・SD への展開

### データベース

`romfs` を実行時に読みます（ゲームデータの同梱は 0 件）。

- ゲームテキスト 105 テーブル・25,208 件
- 生産・強化のレシピ 28,623 件（素材と個数・戻りの端材・セーブ所持数）
- 生産物 → 必要素材 と 素材 → 作れるもの の両方向、各編集画面へのリンク

### セーブマップ

セーブ全体を 201 項目の表として表示します（読み取り専用）。
項目名・オフセット・長さ・現在値と 16 進ダンプ。

## 安全のための仕組み

- 書き込み前に `backups/` へ控えを取る
- エミュレータ起動中は書き込まない（承知のうえで続けることもできます）
- 読み込んだ後にファイルが変わっていたら書き込まない
- 書いた後に読み直して照合する
- 保存前に**何が変わるか**を表示する（機能単位と値の old → new）
- 変更一覧から**その項目だけ**戻せます
- 元に戻す（8 段）・やり直す
- スナップショットとの比較

## 配置

```
SD カードのルート/
└─ switch/
   └─ XXSE/
      ├─ XXSE.nro
      ├─ update.cfg        起動時の更新チェックの設定（初回起動時に作られます）

      └─ mhxx/quest/arc/   クエストの書き出し先
```

hbmenu から起動します。PC 版は XXSE.exe をそのまま実行してください。

## Switch 版の操作

| ボタン | 動作 |
|---|---|
| `ZL` / `ZR` | メインセクション切替 |
| `L` / `R` | サブタブ切替 |
| `L` 長押し 2 回 | 元に戻す（1 回目は確認） |
| `A` | 開く・決定（選択中の行によって動作が変わり、フッターに表示されます） |
| `◀` / `▶` | 数値の増減 |
| `▲` / `▼` | 項目移動 |
| `Y` | 刻み幅・検索・サブ操作 |
| `R` | 数値の直接入力 |
| `X` | 保存（保存前レビューを経ます） |
| `-` 2 回 | 削除（破壊的な操作はすべて 2 回押し） |
| `B` | 戻る・キャンセル |
| `+` | 終了（未保存なら確認） |

画面下のフッターに、その画面で使えるキーが出ます。タッチ操作は 1 回目で選択、2 回目で決定です。

## 起動時の更新チェック（Switch 版・任意）

起動時に **1 回だけ** GitHub の release を見に行き、新しい版があればガイド行の右端に
1 行のバナーで知らせます。通信できなければ**何も表示せずに通常起動**します。

* バナー `新しいバージョン vX.Y.Z があります  [A] 詳細` をタップ、または
  セーブ一覧（起動画面）で `[A]` / `[R]` 長押し → 確認ダイアログ。
* `[A]` でダウンロード（0〜100% 表示、`[A]` で中止）。
* 完了すると `switch/XXSE/XXSE.nro` を差し替えて**その場で新しい版を起動**します。
  差し替えは `XXSE.nro.new` に書き切ってから `XXSE.nro.bak` 経由で行うので、
  途中で失敗しても既存の .nro は壊れません（`.bak` を戻せば復旧できます）。
* `[Y]` で起動時の確認をオン / オフ（`switch/XXSE/update.cfg`）。オフにすると
  起動時にソケットを一切開きません。
* **セーブデータには触れません。** 書き込むのは `switch/XXSE/` の中だけです。

TLS は本体の `ssl` サービスが担当するので、`cacert.pem` の同梱は不要です
（詳細は `switch/README.md`）。

## ビルド

```powershell
# PC 版
cargo build --release -p mhnx-gui -p mhnx-cli

# Switch 版
.\switch\build.ps1

# リリース用 zip
pwsh -File .\tools\make_release.ps1
```

Switch 版のビルドには devkitPro（libnx）と rustup の `aarch64-nintendo-switch-libnx` が必要です。
更新チェックを使う場合は devkitPro の portlib `switch-curl` も入れます
（無くてもビルドは通り、更新チェックだけが無効になります）:

```powershell
$env:MSYSTEM='MSYS'
C:\devkitPro\msys2\usr\bin\pacman.exe -S switch-curl
```

リリース zip には追加のファイルは要りません（CA 証明書は本体が持っています）。
GitHub の release には **`XXSE.nro` という名前で** asset を添付してください
（名前が違う場合は最初の `.nro` を探します）。

## 注意

セーブは必ずバックアップを取ってから使ってください。
書き込み前に `/switch/XXSE/backups/` へ控えを作りますが、自己責任でお願いします。
