# XXSE

Monster Hunter XX (3DS / Switch) のセーブエディタです。

**Alpha v0.4.0**

## 動作環境

| 版 | 動くところ |
|---|---|
| XXSE.nro | Nintendo Switch（Atmosphere 1.12 以降 / ファーム 23.0.1 で確認） |
| XXSE.exe | Windows 10 / 11 |

## できること

Switch 版でできることです。PC 版だけの機能は「実機と PC の違い」にまとめています。

### セーブ編集

- ハンター（名前・所持金・HR・各種ポイント・声・髪型・顔・性別・瞳の色・服）
- アイテム BOX（個数・一括 99・重複整理・空き詰め・上限丸め・アイテム追加）
- 護石（10 種類・スキル・ポイント・スロット・装飾品 3 枠）
- 装備（作成・差し替え・削除・レベル・装飾品・着せ替え）
- マイセット（装備 / アイテム、ポーチ連携）
  - セット名は装備セットもアイテムセットも変えられます（アイテムセットは `[ZR]`、装備セットは名前の行で `[A]`）
- オトモ（名前・レベル・なつき・経験値・スキル・サポート行動・装備）
- 狩猟記録（討伐・捕獲・サイズ、未狩猟のモンスターも表示可）
- ギルドカード（HR・プレイ時間・コメント・カード名・武器使用数・クエスト回数・闘技大会）
- 進行状況（勲章・依頼・クエストのクリア / 既読）
  - クエストの**失敗**は読むだけで、書き換えられません
  - 勲章 132 件・依頼 184 件・クエスト 1508 件は**ゲーム内の日本語名**で表示します（下記「表示する名前」）
- DLC クエスト・配信オトモ
- 3DS ↔ Switch の形式変換
- 起動時に新しい版を確認して、本体の .nro を更新できます
- 名前に改行を入れられます（ハンター名・オトモ名・マイセット名・ギルドカード名・コメント）

### 護石

`charm::TALISMAN_KINDS` の 11 行がそのまま並びです（`amuletData_jpn.gmd` の行順）。

| 番号 | 名前 | レア度 | スロット上限 | スキル1 上限 | スキル2 上限 |
|---|---|---|---|---|---|
| 0 | 装備なし | — | — | — | — |
| 1 | 兵士の護石 | 97 | 1 | +10 | 不可 |
| 2 | 闘士の護石 | 97 | 1 | +10 | 不可 |
| 3 | 騎士の護石 | 98 | 2 | +10 | +13 |
| 4 | 城塞の護石 | 98 | 2 | +10 | +13 |
| 5 | 女王の護石 | 99 | 3 | +8 | +13 |
| 6 | 王の護石 | 99 | 3 | +8 | +13 |
| 7 | 龍の護石 | 99 | 3 | +8 | +13 |
| 8 | 英雄の護石 | 100 | 3 | +10 | +13 |
| 9 | 伝説の護石 | 100 | 3 | +10 | +13 |
| 10 | 天の護石 | 100 | 3 | +10 | +13 |

0 行目は「装備なし」で、選ぶ対象ではありません（選べるのは 1〜10 の 10 種類）。
上限はゲームの護石テーブル（`amuletSkillData00..07`）から測った**実データ**です。

- スキルごとの上限はスキル表が決めます（例: 攻撃 +10、聴覚保護 +7）。種類の上限とスキル表の狭いほうが効きます
- 兵士・闘士は第 2 スキルを持てません
- スキルは種類と枠で選べるものだけが出ます
- **装飾品 3 枠**（+0x06 / +0x08 / +0x0A）は護石編集の下 3 行（装飾品1〜3）で選びます。護石は装備BOX の一覧に出ないので、**入口は護石編集だけ**です（スロット数より後ろの枠は「スロット数が足りません」と出ます）

### クエスト

- 条件 (.mib): 報酬・時間・マップ・初期位置・大型モンスター 5 枠
- 初期配置 (.sem): エリア番号・座標・向き・出現ウェーブ
- 文章 (.gmd): クエスト名・依頼主・依頼内容・成功 / 失敗条件
- 報酬 / 支給品 (.rem / .sup)、小型配置 (.esl)、整合性検査
  - 報酬の**確率 %** を編集できます（グループの合計が 100% でない場合は警告）
- セーブへの導入・セーブ内クエストの削除・SD への展開

### 表示する名前

セーブが持っているのは番号だけなので、画面に出す名前は表から引きます。
勲章・依頼・クエスト名・ステージ名は**同梱**してあるので、`romfs` を指定しなくても
最初から名前で表示されます。

| 項目 | 件数 | 出典のファイル |
|---|---|---|
| 勲章 | 132 | `data/world/awards.tsv` |
| 依頼 | 184（+ 受理 / 完了フラグ） | `data/world/requests.tsv` |
| クエスト | 1508 | `data/world/quests.tsv` |
| ステージ | 31 | `data/world/stages.tsv` |

* 出典: **https://github.com/Nexy451z/mhxx-id-memo**（作者本人のリポジトリ・MIT）
* 取得した commit: `a284583b3bd04b8fe95e559b8b92d9e29bbdca00`（2026-11-09 取得）
* 生成: `python tools/gen_idmemo.py` → `crates/mhnx-core/src/idmemo.rs`
  （手で編集しないでください。表の形が変わると生成器が書き込みを拒否します）
* 名前が引けない行は番号のままにせず、**「名前不明」**と表示します
* `romfs` を指定できるのは PC 版だけです（指定した dump の名前が優先され、外すと
  同梱の名前に戻ります。セーブと一緒に配られたファイルのほうが、そのセーブにとっては
  正しいため）
* アイテム名・スキル名・モンスター名・装飾品名・装備名も同梱の表から引きます
  （`gamedata.rs` / `skills.rs` / `equipnames.rs`。出所は下の「ライセンス」に書いています）

### セーブマップ（生データ）

開いているキャラの 72 行（ヘッダ 1 行 + セーブ本体 3 行 + DLC 3 行 + そのキャラの 65 行）を、
項目名・オフセット・長さ・現在値と 16 進ダンプで表示します。

- `[A]` で行のバイト編集に入り、1 バイトずつ書き換えられます（確認してから書き込み、1 回ごとに元に戻せます）
- `[Y]` で領域名・オフセットから絞り込めます
- 各画面の `[R]` 長押し（詳細）でも、その画面が扱う行から開けます

## 実機と PC の違い

同じ画面でも呼び名が違います（実機側はタブの見出し）。読み替えはこの表で:

| PC 版 | 実機（Switch） |
|---|---|
| クエスト（ファイル） | `SD(.arc)` |
| ギルド | ギルドカード |
| 護石 | 護石一覧 |
| DLC | 公式 / 没クエ / 配信オトモ |

機能の差はこちら:

| 項目 | 実機（Switch） | PC 版 |
|---|---|---|
| データベース（`romfs` のテーブルとレシピ） | 無し（タブがありません） | あり（105 テーブル・25,208 件 / レシピ 28,623 件） |
| ハンターのカラー（9 色の RGBA） | 無し（生データでバイトとして書き換え） | あり |
| ギルドカードの称号・履歴 | 無し | あり |
| 元に戻す段数 | 4 段 | 8 段（設定で最大 16） |
| やり直す | 無し | あり（Ctrl+Shift+Z / Ctrl+Y） |
| スナップショット | 戻すだけ | 比較もできる |
| 護石の装飾品（3 枠） | 護石編集 | 装備タブ（護石の画面にはありません） |
| セーブマップの行数 | 72 行（開いているキャラ） | 201 項目（3 キャラ分すべて） |
| エミュレータ起動中の検知 | 無し | あり（起動中は書きません） |
| 読み込んだ後にファイルが変わっていたら | 検知しません（保存時に差分として出ます） | 書き込みを拒否 |

## 安全のための仕組み

- 書き込み前に `backups/` へ控えを取り、`snapshots/` に回転スナップショットを残す（どちらも 10 個まで）
- 書いた後に読み直して照合し、合わなければ書き込み前の内容に戻す
- 保存前に**何が変わるか**を表示する（機能単位と値の old → new）
- 変更一覧から**その項目だけ**戻せます
- 元に戻す（4 段。`[L]` 長押し 2 回、またはフッターの「元に戻す」を 2 回タップ）
- `[Y]` でスナップショットへ戻せます（確認のうえ書き込み）

## 配置


```
SD カードのルート/
└─ switch/
   └─ XXSE/
      ├─ XXSE.nro
      ├─ update.cfg        起動時の更新チェックの設定（初回起動時に作られます）
      ├─ backups/          書き込み前の控え
      ├─ snapshots/        回転スナップショット（書き込みのたびに 1 つ）
      ├─ saves/            ここに置いたセーブも一覧に出ます
      ├─ csv/              CSV 入出力の書き出し先
      └─ mhxx/quest/arc/   クエストの書き出し先
```

hbmenu から起動します。PC 版は XXSE.exe をそのまま実行してください。

## Switch 版の操作

| ボタン | 動作 |
|---|---|
| `ZL` | セクション（サイドバー）切替 |
| `ZR` | 画面の第 2 操作（検索・一括操作・装備・表示切替など）。クエスト改造の報酬タブでは 個数 → 確率% → 検索 の 3 段（支給品は検索）。持たない画面ではセクション送り |
| `L` / `R` | サブタブ切替（選択リストでは 10 行送り）。**押した時点ではなく離した時点**で効きます（選択リストだけは押した時点） |
| `L` 長押し 2 回 | 元に戻す（1 回目は確認） |
| `R` 長押し | 詳細（生データ）。セーブ一覧では更新ダイアログ（設定の入口） |
| `A` | 開く・決定（選択中の行によって動作が変わり、フッターに表示されます） |
| `B` | 戻る・キャンセル |
| `X` | 保存（保存前レビューを経ます） |
| `Y` | 画面の第 1 切替（刻み幅・検索・表示切替など） |
| `R` | 数値の直接入力（対応する画面のみ）。クエスト改造の報酬 / 支給品タブではアイテム名検索。アイテムセットではポーチへ適用（2 回）。**押した時点ではなく離した時点で実行**されます（長押しの詳細と区別するため） |
| `-` | 削除（2 回押し）。削除するものが無い画面では何もしません |
| `+` | 終了（未保存なら確認）。護石・装備・オトモでは新規 / スキル |
| `◀` / `▶` | 数値の増減（選択リストでは 10 行送り）。装備BOX の種別は 19 種を巡回（護石と未使用を除く） |
| `▲` / `▼` | 項目移動 |
| `R スティック` | 頁送り（`◀` / `▶` で先頭 / 末尾へ） |

画面下のフッターに、その画面で使えるキーが出ます。タッチは行を 1 回目で選び、2 回目で決定します（ボタンは 1 回で動きます）。ただし `[L]` / `[R]` の 1 回押しは離した時点で動きます。

内蔵キーボード（文字入力）を開いている間だけ、キーの意味が変わります（→「内蔵キーボード」）。

### 内蔵キーボード（文字入力）

改行を入れられる欄（ハンター名・オトモ名・マイセット名・ギルドカード名・コメント）は
**必ずこのキーボード**です。1 行の欄はシステムのキーボードを使い、それが開けない環境
（アルバムから起動した等）では理由を出してこちらに切り替わります。

**この画面だけキーの意味が違う**ので、上の表ではなくこちらを見てください。

| ボタン | 動作 |
|---|---|
| `A` | 選択中の文字を入力 |
| `B` | 1 文字削除 |
| `X` | 全消去（2 回押し） |
| `Y` | 濁点 / 半濁点 / 小字（直前の 1 文字を変える） |
| `ZR` | 改行（複数行の欄のみ。1 行の欄では入りません） |
| `ZL` / `L` / `R` | 文字種（ひらがな / カタカナ / 英数字 / 単語・漢字） |
| `+` | 確定 |
| `-` | 取消（入力していた文字は捨てます） |
| `▲` / `▼` / `◀` / `▶` | 文字を選ぶ |

`[B]` は戻るではなく **1 文字削除**、`[-]` は削除ではなく **取消**、`[+]` は終了ではなく
**確定**です。

## 起動時の更新チェック（Switch 版・任意）

起動時に **1 回だけ** GitHub の release を見に行き、新しい版があればガイド行の右端に
1 行のバナーで知らせます。通信できなければ**何も表示せずに通常起動**します。

* バナー `新しいバージョン vX.Y.Z があります  [A] 詳細` をタップ、または
  セーブ一覧（起動画面）で `[A]` / `[R]` 長押し → 確認ダイアログ。
* `[A]` でダウンロード（0〜100% 表示、`[A]` で中止）。
* 完了すると `switch/XXSE/XXSE.nro` を差し替えて**その場で新しい版を起動**します。
  差し替えは `XXSE.nro.new` に書き切ってから `XXSE.nro.bak` 経由で行うので、
  途中で失敗しても既存の .nro は壊れません（`.bak` を戻せば復旧できます）。
* `[Y]` で起動時の確認をオン / オフ（`switch/XXSE/update.cfg`）。オフにすると
  起動時にソケットを一切開きません。
* **セーブデータには触れません。** 書き込むのは `switch/XXSE/` の中だけです。

TLS は本体の `ssl` サービスが担当するので、`cacert.pem` の同梱は不要です
（詳細は `switch/README.md`）。

### 公式 DLC バンドル（任意）

公式クエスト・没クエストのバンドルは**同梱していません**。そのままビルドすると空の
`dlc_bundle_stub.rs` が使われ、クエストの「公式」「没クエ」タブを開いても**0 件**になります
（他の機能はそのまま動きます）。自前のゲームファイルから作る場合:

```powershell
python tools\gen_official_dlc.py
```

* スクリプトは引数を取りません。先頭の `PLAYABLE_DIR` / `DEAD_DIR`（クエストの .arc を
  置いたフォルダ）と `SAVE_PATH`（DLC 領域を含むセーブ）を自分のパスに書き換えてから
  実行します。
* `crates/mhnx-core/src/dlc_bundle_gen.rs` と `official_dlc.bin` を書き出します
  （どちらも .gitignore 済み）。`build.rs` は**両方**揃っているときだけそちらを
  コンパイルし、欠けていれば stub に戻します。
* 件数が 189 / 34 でないとスクリプトは停止します（`assert`）。

Switch 版のビルドには devkitPro（libnx）と rustup の `aarch64-nintendo-switch-libnx` が必要です。
更新チェックを使う場合は devkitPro の portlib `switch-curl` も入れます
（無くてもビルドは通り、更新チェックだけが無効になります）:

```powershell
$env:MSYSTEM='MSYS'
C:\devkitPro\msys2\usr\bin\pacman.exe -S switch-curl
```

リリース zip には追加のファイルは要りません（CA 証明書は本体が持っています）。
GitHub の release には **`XXSE.nro` という名前で** asset を添付してください
（名前が違う場合は最初の `.nro` を探します）。

## 注意

セーブは必ずバックアップを取ってから使ってください。
書き込み前に `/switch/XXSE/backups/` へ控えを作りますが、自己責任でお願いします。
