# XXSE

Monster Hunter XX (3DS / Switch) のセーブエディタです。

**Alpha v0.2.5**

## 動作環境

| 版 | 動くところ |
|---|---|
| XXSE.nro | Nintendo Switch（Atmosphere 1.12 以降 / ファーム 23.0.1 で確認） |
| XXSE.exe | Windows 10 / 11 |

## できること

- セーブ編集（名前・所持金・HR・各種ポイント・アイテム・お守り・装備・狩猟記録・ギルドカード・オトモ・マイセット）
- クエスト (.arc) の編集とセーブへの導入
  - 条件 (.mib): 報酬・時間・マップ・初期位置・大型モンスター5枠（種類 / 体力 / 攻撃 / 防御 / サイズ% / 出現数 / スタミナ / 変動幅 / 獰猛・特殊）
  - 初期配置 (.sem): 大型モンスターの初期エリア番号・X / Y / Z 座標・向き角度・出現ウェーブ
  - 文章 (.gmd): クエスト名・依頼主・依頼内容・主なモンスター・成功 / 失敗条件
  - 報酬 / 支給品 (.rem / .sup)、小型配置 (.esl)、整合性検査
- データベース（romfs を実行時に読む / 同梱 0）
  - ゲームテキスト 105 テーブル・25,208 件
  - 生産・強化のレシピ 28,623 件（素材と個数・戻りの端材・必要素材のセーブ所持数）
  - 生産物 → 必要素材 と 素材 → 作れるもの の両方向、各編集画面へのリンク
- 3DS ↔ Switch の形式変換
- 実機の本体セーブを直接編集（アルバム / Applet 起動時の内蔵ソフトキーボード対応）

## 配置

```
SD カードのルート/
└─ switch/
   └─ XXSE/
      ├─ XXSE.nro
      ├─ backups/          書き込み前の控え
      └─ mhxx/quest/arc/   クエストの書き出し先
```

hbmenu から起動します。PC 版は XXSE.exe をそのまま実行してください。

## Switch 版の操作

| ボタン | 動作 |
|---|---|
| `ZL` / `ZR` | 上段のメインセクション切替（ファイル / ハンター / アイテム / 護石・装備 / オトモ・記録 / クエスト） |
| `L` / `R` | 現在のセクション内のサブタブ切替 |
| `A` | 開く・一覧選択・編集 |
| `◀` / `▶` | 数値の増減 |
| `Y` | 刻み幅切替（`±1` / `±10` / `±100` / `±1000`）・検索・サブ操作 |
| `X` | 変更を保存 / 反映 |
| `B` | 戻る・キャンセル |

## ビルド

```powershell
# PC 版
cargo build --release -p mhnx-gui -p mhnx-cli

# Switch 版
.\switch\build.ps1

# リリース用 zip
pwsh -File .\tools\make_release.ps1
```

Switch 版のビルドには devkitPro（libnx）と rustup の `aarch64-nintendo-switch-libnx` が必要です。

## 画面

左に項目リスト、右に詳細・数値操作・一括プリセットを並べた2ペイン構成です。

- 選択中の行 … 枠線と左端のアクセントバー
- 危険な操作 … 赤系。削除は2回押しで確定
- 文字 … 長い項目名や説明は自動でクリップし、文字かぶりを防止

## 注意

書き込み前に `/switch/XXSE/backups/` へ控えを作ります。セーブは必ずバックアップを取ってから使ってください。
